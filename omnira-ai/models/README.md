# Models

This directory stores model registries, adapters, quantization artifacts, and model cards for OMNIRA AI.

- `registry/` contains base model mappings, OMNIRA model definitions, and deployment targets.
- `adapters/` is reserved for LoRA and related artifacts.
- `quantized/` is reserved for local optimized model packages.
- `model-cards/` stores human-readable documentation for each OMNIRA model.
