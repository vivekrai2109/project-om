# OMNIRA Platform 7B v0.1

## Summary

OMNIRA Platform 7B v0.1 is the first internal target model for infrastructure, DevOps, Azure, Terraform, Kubernetes, CI/CD, and SRE workflows.

## Base family

- Derived from the Qwen family.
- Initial fine-tuning path uses QLoRA rather than full-parameter training.

## Intended use

- Platform engineering assistance.
- Azure and Kubernetes reasoning.
- Terraform and CI/CD guidance.
- Safety-aware operational planning.
