# Roadmap

## Phase 1: Local MVP

Create the monorepo, OMNIRA Core API, OMNIRA Studio UI, model router, memory skeleton, RAG skeleton, safety boundaries, and developer docs.

## Phase 2: Memory + RAG

Move memory to PostgreSQL, add pgvector, improve retrieval quality, and add ingestion workflows for project docs and personal knowledge.

## Phase 3: Agents + Tools

Expand OMNIRA Agents, add approval-gated tool execution, and improve orchestration for multi-step tasks.

## Phase 4: Dataset Capture

Capture supervised, preference, and evaluation data from real usage patterns with privacy-aware controls.

## Phase 5: Fine-tune OMNIRA Platform 7B

Use QLoRA and curated infrastructure datasets to train the first internal OMNIRA Platform model.

## Phase 6: Self-host through vLLM

Serve internal models through vLLM with a provider-independent API surface.

## Phase 7: Private Jarvis-style System

Combine local memory, tools, agents, speech, and self-hosted models into a private personal intelligence environment.

## Phase 8: SaaS/Productization

Evaluate multi-tenant product packaging, hosted inference options, governance, and enterprise-grade controls.
