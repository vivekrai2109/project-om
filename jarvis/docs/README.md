# Docs

This folder follows the current Jarvis plan: Jarvis is the operator, Agent Hub is the runtime, and our own models should become the default over time.

## Jarvis
- `MISSION.md`: mission and principles
- `ROADMAP.md`: phases and strategy
- `TASKS.md`: execution backlog
- `current_status.md`: implemented shell, OMNIRA, learning, and autonomy status
- `JARVIS_LITE_MVP.md`: MVP scope and non-goals
- `ARCHITECTURE.md`: system view and boundaries

## Frontend
- `VOICE_CENTRIC_OPERATING_MODEL.md`: desktop and voice behavior
- `CINEMATIC_UI_PLAN.md`: primary cinematic shell plan and rendering stack

## Backend
- `TECHNICAL_SPEC.md`: runtime surfaces and contracts
- `ARCHITECTURE_LAYERS.md`: layered system diagram
- `PLATFORM_INVENTORY.md`: reusable modules and refactor targets
- `TRACING.md`: observability and trace format

## Models
- `MODEL_PLATFORM_STRATEGY.md`: own-model-first strategy
- `LOCAL_MODEL_AZURE.md`: self-hosted model serving path
- `FINETUNE_PLAN.md`: tuning and eval plan

## Policy
- `REPO_POLICY.md`: repo guardrails
- `NAMING_CONVENTIONS.md`: naming rules

## Notes
- `LOCAL_MODEL_AZURE.md` and `FINETUNE_PLAN.md` are implementation-path docs, not top-level product source-of-truth docs.
- `current_status.md` replaces the earlier temporary agent handoff note and is the current concise implementation tracker.
- Older duplicate docs were removed because they were stale or superseded by the current roadmap and architecture set.
