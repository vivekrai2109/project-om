# Mission

Build a local-first, supervised AI assistant platform that can coordinate specialist agents, adapt to project and user context, and execute useful workflows reliably with explicit approvals for risky actions.

## Principles
- Local-first by default; cloud-ready when needed.
- Clear separation of orchestration vs. specialist work.
- Fast feedback loops via tracing, runs, and memory.
- Safe, auditable actions with visible approval gates.
- Extensible tools registry and agent profiles.
- Legitimate user-assistive workflows only, with consent for recording or analysis.
